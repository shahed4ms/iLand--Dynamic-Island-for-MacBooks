## ✨ Overview

**iLand** is a native macOS application inspired by the iPhone Dynamic Island. It brings useful system activity, music controls, and quick information to the top of your MacBook screen.

Built with SwiftUI and AppKit, iLand combines a minimal dark-glass appearance with smooth animations and contextual activity indicators.

## 🚀 Features

- 🎵 **Music Player** — Display music information and access playback controls.
- ⬇️ **Safari Downloads** — Show download activity and progress.
- 🔋 **Battery Status** — Display battery information and highlight low-battery or charging states.
- 🛍️ **App Store Activity** — Detect when the App Store is open.
- ⚡ **Interactive Island** — Expand and collapse the island to reveal additional information.
- ⚙️ **Menu Bar Controls** — Access Settings and quit the application.
- 🎨 **Minimal Interface** — Dark styling, rounded corners, subtle shadows, and animated transitions.

> Feature availability and behavior depend on the current implementation and macOS permissions.

## 🛠️ Tech Stack

- **Language:** Swift
- **UI Framework:** SwiftUI
- **Window Management:** AppKit
- **IDE:** Xcode
- **Platform:** macOS
